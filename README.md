# ChocMath

The honest math of bean-to-bar chocolate: roast and winnow loss, recipe ratios by darkness target, temper working points by chocolate type, bar yield, and ingredient cost per bar.

Static site. No build, no backend, no tracking. Open `index.html`.

- **Engine:** `engine.js` - pure functions, tested in Node.
- **App:** `app.html` - four cards (nibs, recipe, temper, bars/cost) with batch presets.
